# webServicePD
## Структура репозитория
Кратко, где что лежит:

- Docker и окружение
	- Dockerfile: образ для запуска сервиса
	- docker-compose.yaml, docker-compose_nginx.yaml: сборка и запуск контейнеров
	- requirements.txt: зависимости Python
- Приложение
	- app/main.py: точка входа FastAPI
	- app/routers/: HTTP-роуты по модальностям (hand, gait, voice, mimic, tremor)
	- app/modalities/: бизнес-логика и обработка данных по модальностям
		- hand/, gait/, voice/, mimic/: сервисы, конфиги и обработка сигналов
- Статика и шаблоны
	- static/: css и js для фронта
	- templates/: html-шаблоны страниц
- Инфраструктура
	- core/: клиенты и общие утилиты (например, minio)
	- nginx/: конфиги и сертификаты для reverse-proxy

## Запуск c использованием docker
Склонировать репозиторий, переключиться на его директорию (cd webServicePD) и перейти к ветке refactoring/new_structure

Запуск приложения производится с помощью докера, который нужно установить заранее. (В случае windows для начала ставиться ядро Linux wsl, а далее приложение Docker Desktop). После установки докера, находясь в корне репозитория прописываем команду:

```
docker compose up -d
```
После успешной сборки контейнера сайт будет доступен по ссылке http://localhost:8000/

## Запуск c использованием виртуального окружения
Альтернативой докеру является использование виртуального окружения (Однако у меня этот способ много проблем вызывал, так как mediapipe начинал просить версии библиотек c++, установки непонятных пакетов и тд):

Слоздаём виртуальное окружение

```
python -m venv venv
```

Активируем его:

```
venv\Scripts\activate  
```
И устанавливаем все необходимые зависимости:
```
pip install -r requirements.txt
```

Запуск производится командой:

```
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
сайт будет доступен по ссылке http://localhost:8000/


## Запуск на сервере
При запуске на сервере важно учитывать, что доступ к камере в браузере работает только по HTTPS, по этому нужно использовать nginx. Основное, что нужно будет сделать это сгенерировать сертификаты безопасности через certboot например и получить домен - это можно сделать через бесплатные сервисы, которым кидаешь ip сервера, а они на основе его делают домен (я использовал sslip.io)

В корне репозитория для nginx есть файл docker-compose_nginx.yaml для связки приложения и nginx.

Каких то более подробных гайдов по этому поводу не могу дать, потому что сидел и настраивал это всё на самом сервере, тут надо на месте разбираться

После настройки HTTPS камера будет доступна в браузере по адресу вида https://your-domain/.
