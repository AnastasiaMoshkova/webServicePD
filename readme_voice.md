## Модуль голоса (app/modalities/voice)

Реализован полностью: запись с микрофона или загрузка файла, трёхканальное спектральное представление, ансамбль из 4 моделей ResNet18-light, late fusion через усреднение, акустические признаки Praat (jitter / shimmer / HNR). Модели: `app/modalities/voice/models/final_cv_fold_{1..4}/best.pt`.

### Что делает

Принимает аудиозапись протяжной гласной «а», возвращает бинарную классификацию PD / HC, вероятность PD, акустические признаки и визуализации (форма волны + трёхканальная спектрограмма).

### Пайплайн

Аудиофайл загружается с частотой дискретизации 16 кГц. Из сигнала извлекается фиксированный сегмент: первые 0.5 с отбрасываются для устранения переходных процессов, после чего берётся фрагмент длительностью 1.5 с. По этому фрагменту рассчитываются три спектральных представления: логарифмическая мел-спектрограмма (R-канал), хромограмма на основе кратковременного преобразования Фурье (G-канал) и мел-частотные кепстральные коэффициенты (B-канал). Каждое представление нормализуется в диапазон 0–255 и приводится к размеру 224×224 пикселей, после чего три матрицы объединяются в одно RGB-изображение. Оно подаётся на вход ансамблю из четырёх нейросетевых моделей ResNet18-light: каждая возвращает логит, к которому применяется сигмоида, а итоговая вероятность вычисляется как среднее по всем моделям. Параллельно по сохранённому WAV-файлу через библиотеку Praat рассчитываются акустические признаки jitter, shimmer и HNR. Все результаты собираются в единый JSON-документ и сохраняются в подпапку текущей сессии.

### Файлы

- `app/routers/voice.py` — HTTP-роуты (`/voice`, `/voice/upload`, `/voice/process`)
- `app/modalities/voice/service.py` — `VoiceService.process()`
- `app/modalities/voice/processing/three_channel.py` — трёхканальное представление
- `app/modalities/voice/processing/features.py` — библиотечные признаки
- `app/modalities/voice/processing/inference.py` — `VoiceClassifier` (ансамбль)
- `app/modalities/voice/models/resnet18_light.py` — архитектура
- `app/modalities/voice/configs/voice.yaml` — конфиг (пути, порог, упражнения)
- `templates/voice.html`, `static/js/voice.js` — UI

### Модель

ResNet-18 backbone (ImageNet-pretrained, заморожен кроме `layer4`) + `Dropout(0.3) + Linear(512 → 1)`. Обучена в проекте `Parkinson_DL-master` (LOGO + StratifiedGroupKFold, 4 фолда, adversarial suppression пола, `λ = 0.25`).

**Метрики лучшей модели (ResNet-A2, фаза 2):**

| Задача | Balanced Accuracy | F1 | AUC |
|---|---|---|---|
| PD vs. HC | 0.9272 | 0.9606 | 0.9257 |
| Early PD vs. HC | 0.8956 | 0.9275 | 0.8900 |

Ансамбль = усреднение `sigmoid(logit)` по 4 фолдам, порог 0.5.
